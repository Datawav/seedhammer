# Passphrase engraving privacy

Passphrase plates use ordinary text engraving. Sound and engraving time can
reveal information about the passphrase, even when two passphrases have the same
length. The offer warns about this and selects SKIP by default. Select ENGRAVE
PASSPHRASE explicitly only in a private environment.

Seed-plate timing protections do not apply to this optional plate. The warning
and default selection leave the engraving algorithm unchanged.
